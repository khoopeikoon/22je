## 出入

![从街上看 22 Jalan Elok。门牌号 22 在左侧的门柱上。](../../assets/img/guide/facade.webp)

- **大门：** 装有密码锁。我们会在您入住前，连同 Wi-Fi 资料一起把密码发给您。
- **钥匙：** 每个房间配 **两把房间钥匙** 和 **两张大门门卡**。闸门遥控器只提供给 **一位住户**。
- 进出时请务必关好前闸门并锁上大门，即使只是出去一会儿。
- 切勿把大门密码告诉任何其他人。
- **门锁电池：** 如果门锁提示电量不足，请告诉我们，我们会更换电池。电池完全耗尽时，键盘会没有反应。开门方法：
  1. 从大门外的鞋柜取出备用的 **9V 电池**：在 **右下方鞋柜的右上角**。如果拿不到，任何便利店都有售（9V 碱性电池，型号 6LF22）。
  2. 把电池的两个电极贴住 **门外键盘底部的紧急触点**。
  3. 保持贴住，然后照常输入密码开门。
  4. 通知我们，以便我们更换门锁电池。
- **如果门锁完全失灵**（例如上面的电池方法也不管用）：房子里有一个 **密码锁盒，内有备用的手动钥匙**，位置会在您入住时告诉您。锁盒密码您已经有了：我们会在您入住前连同大门密码一起发给您，请把它存在不连房子 Wi-Fi 也能查看的地方。忘记了？任何时间都可以通过我们的 WhatsApp 自动回复获取（把入住时我们告诉您的暗语发到 Kevin 的号码），也可以给 Kevin 发消息或打电话。
- 如果遗失钥匙、门卡或遥控器，请立即告诉我们，以便我们确保房屋安全。补配费用为 **每把钥匙或每张门卡 S$10**、**每个遥控器 S$50**。

## 厨房电器

厨房电器全部是三星（Samsung）品牌。使用后请擦干净，并保持原样。

### 电磁炉

![电磁炉。控制键在前缘。](../../assets/img/guide/induction-hob.webp)

1. **只能使用适用于电磁炉的锅具。** 锅底必须平整且带磁性：冰箱磁铁能吸住的锅就可以用。
2. 轻触 **⏻** 开启电磁炉，把锅放在 **三个加热区** 之一，然后用手指在 **0–9 滑条** 上滑动调节火力（**Max** 最强）。大加热区是双圈设计，会根据锅的大小自动调整。
3. 煮食时请打开炉灶上方的 **抽油烟机**。
4. **需要马上全部停止？** 轻触 **‖** 即可同时暂停所有加热区。
5. 用完后再次轻触 **⏻** 关闭。煮完后玻璃面会烫一段时间，请勿触摸。
6. **如果按键没有反应，** 可能开启了童锁：按住锁形按键 3 秒即可解除。

移动锅具时请提起，不要在玻璃面上拖动，以免刮花。溢出的食物请等炉面冷却后再擦干净。

### 烤箱

![嵌入式烤箱。左边的旋钮选择烹调模式，右边的旋钮设定温度。](../../assets/img/guide/oven.webp)

1. 转动 **左边旋钮**，选择所需的烹调模式，例如热风或烧烤。
2. 转动 **右边旋钮** 设定温度，然后轻触 **OK**。
3. 先让烤箱预热，再放入食物，并请务必使用隔热手套。
4. 用完后，把 **左边旋钮** 转回 **关闭** 位置。

请不要在烤箱底部铺锡纸；不用烤箱时请关好烤箱门：烤箱门打开时，旁边的洗碗机无法打开。

### 多功能微波炉

![小型多功能微波炉。](../../assets/img/guide/combi-microwave.webp)

这是一台还能烧烤和烘焙的微波炉。

- **快速加热：** 把食物放在适用于微波炉的器皿中，关上门，按 **Start / +30s**。每按一次，以最大火力增加 30 秒。
- **其他模式：** 轻触所需模式，用 **▲ ▼** 设定时间，轻触 **OK**，再按 **Start**。
- **Stop / Eco：** 按一次暂停，按两次取消。
- **用微波加热时，切勿放入金属、锡纸或密封容器。** 使用烧烤或烘焙模式时，器皿和炉内会非常烫。
- **如果按键没有反应，** 可能开启了童锁：按住锁形图标 3 秒即可解除。

### 洗碗机

![洗碗机](../../assets/img/guide/dishwasher.webp)

> **⚠️ 打开洗碗机前，请先关好烤箱门。**
>
> 洗碗机和烤箱在转角处相接，烤箱门打开时，洗碗机门无法打开。

![打开的洗碗机，烤箱就在转角旁边。必须关上烤箱门，洗碗机门才能打开。](../../assets/img/guide/dishwasher-open.webp)

1. 先把剩菜刮进垃圾袋。
2. 盘子放在下层架，面朝中间；杯子和玻璃杯倒扣放在上层架。确保没有东西挡住旋转喷臂。
3. 在门内侧的洗涤剂盒里放 **一粒洗碗块**，然后关上盒盖。**洗碗块由我们提供**，放在水槽下方。
4. 关上门，在门顶边缘的控制面板上选择程序并启动。
5. 洗好后，请把干净的碗碟收好。如果发现洗碗机里装满了洗好的碗碟，请先清空，再放入您的碗碟。

木砧板、木制餐具、不粘锅以及没有标明"可用洗碗机清洗"（dishwasher safe）的物品，请不要放进洗碗机，改用手洗。

## 垃圾

新加坡对垃圾处理要求严格，而且天气炎热，散落的垃圾很快就会招来蚂蚁和害虫。**屋内没有共用垃圾桶**，所以请自行把垃圾拿出去。

1. 所有垃圾都要装袋，并 **把袋口扎紧**。
2. 湿的厨余请先单独用小袋包好，以免漏水。
3. 把垃圾拿到 **前闸门旁的绿色垃圾桶**。切勿把垃圾袋留在屋内任何地方，包括厨房。
4. 请盖好垃圾桶盖。切勿把垃圾袋放在垃圾桶旁边，哪怕只是一晚。

垃圾 **每天** 都有人收集。

**回收：** 干净、干燥的纸张、塑料、玻璃和金属可以放进 **蓝色回收桶**。如果不确定能否回收，请和其他垃圾一起放进绿色垃圾桶。

## 洗衣露台（5 楼）

洗衣露台是 5 楼的开放式露台，与 Aurelia 金曦套房隔着电梯口相对。**洗衣是自助式的：** 请自行在这里清洗。洗衣露台 **免费使用，随时开放**。深夜和清晨使用时，请尽量保持安静。

**不知道机器怎么用？** 尽管问我们，我们很乐意示范。

![烘干机（上）和洗衣机（下），左边是用于手洗和浸泡的水槽](../../assets/img/guide/washer-dryer.webp)

两台机器都是 **三星 Samsung Bespoke AI** 型号，只有一个旋钮。**洗衣机**（9 公斤前置滚筒，型号 WW90DB8U94GBSP）是 **下面那台**，**烘干机**（10 公斤热泵烘干机，型号 DV10BB9440GBSP）在 **上面**。机器上的文字是英文，每台都有三个控制键：

| 控制键 | 作用 |
|---|---|
| **⏻ Power（电源）** | 开机和关机 |
| **旋钮** | 转动选择程序（程序名称会显示在屏幕上）；按下可查看选项 |
| **▷‖ Start / Pause（开始 / 暂停）** | 启动程序，或暂停 |

### 使用洗衣机（下面那台）

1. **准备：** 清空口袋（纸巾和硬币最容易出问题），拉好拉链，把精细衣物和胸罩放进洗衣网袋。深色和白色衣物请分开洗。
2. **放入衣物：** 衣物放松散些，最多放到滚筒的 **四分之三左右**。关上门，直到听到"咔嗒"一声。
3. **加洗衣液：** 拉出洗衣机左上方的抽屉，把一瓶盖的洗衣液倒进洗衣液格。请不要使用大的 Auto Dispense（自动投放）储液箱，我们不会添加。**洗衣液由我们提供**：请使用机器对面架子上的那瓶。一瓶盖就足够了，前置滚筒洗衣机只需要很少的洗衣液。
4. 按 **⏻ Power**。
5. **转动旋钮** 选择程序：
   - **AI Wash** 或 **Cotton**（棉质）：日常衣物、毛巾和床品
   - **Synthetics**（化纤）：运动服、聚酯纤维
   - **Delicates**（精细衣物）或 **Wool**（羊毛）：平时需要手洗的衣物
   - **Quick Wash 15'**（15 分钟快洗）：少量、轻度穿着的衣物
   - **Super Speed**（超快洗）：赶时间时洗一般分量的衣物（约 39 分钟）
   - **Bedding**（床品）和 **Towels**（毛巾）：如其名
6. 按 **▷‖ Start**。机器运转时门会锁上。
7. 洗好后请尽快取出衣物，并 **让门微微打开**，让滚筒通风。

**漏放了东西？** 按 **▷‖** 暂停。门锁解开后即可放入，关上门再按一次 **▷‖**。

### 使用烘干机（上面那台）

> **⚠️ 每次烘干前都要清理棉絮过滤网，否则衣服烘出来还是湿的。**
>
> 过滤网堵塞会阻挡气流，烘干机运转更久，衣服却还是湿的。清理只需十秒钟：见下面第 2 步。即使上一位住户没有清理，也请您清理一下。

1. **查看衣物洗涤标签。** 羊毛、丝绸、蕾丝或任何标有"do not tumble dry"（不可滚筒烘干）的衣物都不能烘干。切勿放入鞋子、背面有橡胶的地垫，或任何含橡胶或海绵的物品。
2. **每次烘干前清理棉絮过滤网。** 过滤网在门口内侧。取出、打开，用手指把棉絮抹掉，再合上并插回原处。不清理的话，衣服会烘不干。
3. 把衣物松散地放入，关上门。
4. 按 **⏻ Power**，**转动旋钮** 选择程序（大多数衣物适用 **AI Dry** 或 **Cotton**，运动服适用 **Synthetics**），然后按 **▷‖ Start**。不需要倒水：烘干机直接排水到下水管。
5. 程序结束后请马上取出衣物，这样比较不会起皱。

### 请勿

- 让任何一台机器超载，或清洗、烘干背面有橡胶的地垫或鞋子。
- 程序结束后把衣物留在机器里。其他住户可能在等着用。
- 在烘干机上面放东西，或倚靠叠放的机器。
- 打开烘干机底部前方的盖子。那个过滤网由我们清理。

### 如果出现问题

- **门打不开：** 程序结束后请等一两分钟，门会自动解锁。如果还是打不开，请联系我们。切勿强行打开。
- **屏幕显示错误代码：** 请拍下屏幕，通过 WhatsApp 发给我们。
- **地上有水：** 按 **⏻** 关掉机器，然后联系我们。

## 安静时间与住宿守则

- **不得饲养宠物。**
- 未经我们同意，请勿在房间之间搬动家具，或在墙上张贴、悬挂任何物品。

## 退租

1. 请提前告诉我们您的退租日期和时间。
2. 请把房间整理干净，清空您在冰箱里的食物，并把垃圾拿到前闸门旁的垃圾桶。
3. **离开前请拍下房间照片**，以作保障。请拍下整个房间、浴室，以及任何您希望留有记录的地方。请保留照片，直到押金退还为止。
4. 请归还两把房间钥匙、两张门卡，以及您持有的闸门遥控器。如有遗失，每把钥匙或每张门卡收费 S$10，每个遥控器收费 S$50。
5. 您退租后，我们会检查房间，并在 7 天内退还押金。
